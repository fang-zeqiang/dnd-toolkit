# DND Toolkit 设计说明

## 结构

- `/`：仅负责展示并导航至两个工具。
- `/tavern/`：原样保存生产环境中的巨魔颅骨酒馆工具。
- `/map/`：原样保存 GRIDBOUND 战图印制坊。

三个页面均为独立静态 HTML，不共享运行时代码。

## 约束

- 不使用框架、包管理器、构建工具、第三方脚本或外部 CDN。
- 工具 HTML 不格式化、不修改内部 CSS 或 JavaScript。
- Git 白名单只允许首页、两个工具、README、`.gitignore` 和本说明。
- PDF、表格、压缩包、测试地图、角色资料、私人图片及凭据不得提交。

## 首页

首页采用深色奇幻视觉，以两张可聚焦的链接卡片呈现工具。桌面双列、移动端单列；使用系统字体、内联 CSS、明确的 hover 与 `focus-visible` 状态，并尊重减少动画偏好。

## 部署与验收

仓库根目录直接部署至现有 Vercel 项目 `troll-skull-tavern-tool`。发布顺序为本地验收、Preview 验收、连接 GitHub、Production 验收。三个路由必须返回 HTTP 200，首页导航正确，两个工具的主要交互、存档与导出可用，控制台无新增错误。

## 回滚

生产异常时，将生产流量回滚至切换前记录的成功部署。不得删除现有项目、域名、DNS 配置或历史部署。
